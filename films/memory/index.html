Memory is an experience

Why remembering is rebuilding, not replaying

9 minBeginner12 chapters

A memory is not a file you open. It is rebuilt each time you recall it, from old pieces and present understanding. The film walks through the evidence, from Bartlett to reconsolidation, and shows how distance and warmth can shift what we see, without inventing what happened.

What to take away

  • Remembering is rebuilding: the pieces are old, but the scene is assembled new each time.
  • A single word in a question can reshape what people remember, which is how memory normally works.
  • When a memory is recalled it briefly becomes open to updating, though scientists are still mapping when and how.
  • Reinterpreting is not inventing: the events stay the same, and understanding someone is not excusing them.
  • Confidence is not accuracy, so the aim is a truer story held with curiosity, not one that only feels good.
