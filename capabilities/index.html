Capabilities

What goes into a model

A language model is a bundle of separate abilities. Some are fixed when the model is designed. Some are learned from raw text in pre-training. Others are taught afterwards, one at a time, or decided when the model is served. For each one: how it is measured, what data it needs, which recipes improve it, and what is still missing.

The list follows how the field already splits things up: benchmark suites such as HELM report accuracy next to calibration, robustness, fairness, bias, toxicity and efficiency, and model cards list languages, context length, modalities and tool use.
