Capabilities · Input and memory

Long context

The model finds and uses information from far back in a long input.

1Where it comes from

DesignMost
Pre-trainingMost
Fine-tuningA little
PreferencesNot here
RLNot here
DeploymentA little
Design and pre-training

It depends on the architecture and on training with long sequences. A long context window does not mean the model uses it.

Post-training and deployment

Fine-tuning on long conversations can help, but the gains are hard to show in generated answers.

2How to measure it

  • RULERSynthetic tasks that test how much of the context window a model really uses.
  • LongBenchLong-document tasks in English and Chinese.
  • Lost in the MiddleShows that models use the start and end of a long input better than the middle.
  • Paired retrieval testsScore the same answer with and without the earlier evidence in the prompt.
